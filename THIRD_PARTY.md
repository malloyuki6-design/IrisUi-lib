# Third-party icon sources

IrisHub does not bundle third-party icon artwork. It supports namespaced identifiers and a registration API so projects can provide their own Roblox-hosted assets.

Lucide Icons: https://lucide.dev/
Geist Icons: https://vercel.com/geist/icons
Craft Icons: https://www.figma.com/community/file/1415718327120418204

Projects should review the current license terms of any third-party assets they import or convert before redistributing them.
