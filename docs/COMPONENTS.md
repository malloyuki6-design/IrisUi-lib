# IrisHub Components

| Component | Core purpose | Useful methods |
|---|---|---|
| Section / Accordion | Collapsible grouping | `Expand`, `Collapse`, `Toggle` |
| Label | Compact text | `Set` |
| Paragraph | Rich explanatory copy | `Set` |
| Divider | Visual separation | `SetVisible` |
| Button | One-shot action | `SetEnabled`, `SetCallback` |
| Toggle | Boolean state | `Set` |
| Dropdown | Single selection | `Set`, `SetOptions`, `FindOption`, `Clear`, `Open`, `Close` |
| MultiDropdown | Multiple selections | `Set`, `Select`, `Deselect`, `SelectAll`, `GetSelected`, `Clear` |
| ImageDropdown | Image-first selection | `Set`, `SetOptions`, `Toggle` |
| Slider | Numeric control | `Set` |
| Input | Text entry | `Set` |
| Keybind | Keyboard binding | `Set` |
| ColorPicker | RGB/hex color editing | `Set`, `Open`, `Close` |
| Image | Large media panel | `Set` |
| Avatar | User/avatar panel | `Set` |
| Card | Information container | `Set` |
| Loading | Busy state | `Set` |
| Progress | Numeric progress | `Set`, `SetRange` |
| Status | Live state indicator | `Set` |
| Badge | Compact status chip | `Set`, `SetColors` |
| KeyValue | Label/value metadata | `Set`, `SetKey` |
| Alert | Informational callout | `Set` |
| CodeBlock | Readable code with copy | `Set`, `SetLanguage`, `Copy` |
| Modal | Confirm/cancel overlay | `Destroy` |
| ContextMenu | Action list | `Open`, `Close`, `Toggle`, `SetItems` |
| Tooltip | Hover explanation | `Show`, `Hide`, `Destroy` |
| Search | Reactive text search | `Set` |
