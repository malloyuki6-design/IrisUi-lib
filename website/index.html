01

WHY IRISHUB

A framework, not a menu script.

Consistent API

Every component follows the same object model, making large interfaces easier to extend and maintain.

Animation system

Reusable tween behavior powers hover, press, open, close, and state transitions without visual clutter.

Theme engine

Switch themes at runtime, register your own palette, or override selected design tokens.

Lifecycle aware

Connection bags and destruction paths are built into the component model to reduce cleanup mistakes.

Developer-first

Returned component references expose state and lifecycle controls so your UI can react without rebuilding it.

Ready to fork

The repository includes examples, tests, API documentation, a showcase site, and a standalone distribution.

02

WHAT'S NEW

More control without more clutter.

Resizable windows

Built-in min/max sizing, a resize grip, animated maximize behavior, and explicit focus management.

Reactive primitives

Progress, status, badges, alerts, key/value rows, and code blocks join the core control set.

Safer rerenders

Temporary dropdown and context-menu connections are isolated so dynamic option lists do not accumulate listeners.

QUICK START

Drop it in and start building.

Showcase.luau
local IrisHub = require(game.ReplicatedStorage.IrisHub)

local UI = IrisHub.Create({
    Name = "MyInterface",
    Title = "My Hub",
    Subtitle = "Powered by IrisHub v2",
    Theme = "Iris",
    UIScale = 1,
    ToggleKey = Enum.KeyCode.RightControl
})

local Window = UI.Windows[1]
local Main = Window:GetTab("Main")

local progress = Main:Progress({
    Title = "Loading",
    Min = 0,
    Max = 100,
    Default = 72
})

Main:Toggle({
    Title = "Feature",
    Description = "Reactive state",
    Default = true,
    Callback = function(value)
        progress:Set(value and 100 or 0)
    end
})
